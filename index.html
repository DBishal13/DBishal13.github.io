02 · GIS Administrator

Enterprise GIS that stays up, and stays clean.

ArcGIS Enterprise and Portal administration, feature services, multi-user editing and the PostgreSQL / PostGIS databases underneath.

  • Published a taxonomy as a feature service with editor tracking and concurrent multi-user editing, plus a read-only REST API for vendors.
  • Moved 8M+ images and 65M+ annotations into an FME-to-PostGIS pipeline with versioning, cutting 100+ columns to ~50.
  • Ran PostgreSQL / PostGIS databases, Cloud-Optimized GeoTIFFs and automated QA in FME, ArcPy and ModelBuilder.

03 · Open-source developer

Tools other GIS people pip install.

Published Python packages, an MCP server for AI agents, and core contributions to a flood modeling framework. Built in the open, documented, tested.

  • road-centerline on PyPI: CRS-aware road centerline extraction from polygons, worldwide.
  • geomlint on PyPI: CI-first validity, topology and CRS checks for vector data.
  • One of four core contributors to PyWMP, an open-source flood modeling framework, and author of HazardMCP.
